## ✨ Features
- **Add New Books:** Enter title, author, genre, total pages, and reading status.
- **Reading Status Tracking:** Organize books across *Want to Read*, *Currently Reading*, and *Completed*.
- **Progress Tracking:** Update pages read and monitor reading progress.
- **Search & Filter:** Search titles/authors and filter by status or genre.
- **Data Persistence:** Automatically saves your reading list to browser `localStorage`.
- **Responsive UI:** Clean, modern interface styled with Tailwind CSS.
